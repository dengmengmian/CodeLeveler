# Methodology

Canonical protocol: [`docs/evaluations/MA-VALUE-001.md`](../../../../../docs/evaluations/MA-VALUE-001.md).

Hypothesis: multi-agent reduces coding-task cost or improves quality (H1),
versus no measurable improvement (H0).

PASS needs all three:

1. Task success does not drop versus single-agent.
2. At least one of turns / tokens / wall time / verification / useful child findings improves.
3. Child output is used by the parent.

Spawn rate is a diagnostic. It is not a success metric.
