# Safety evaluation (E005)

Observer of ownership, sandbox, and permission. These are **not** adoption
tasks: several historical probes instruct the model to spawn. Including them
in P_natural inflates adoption.

Score EventLog with the same parser. Counters:

| field | source |
| --- | --- |
| `safety.ownership_granted` | `delegation_stage action=ownership_granted` |
| `safety.ownership_denied` | `delegation_stage action=ownership_denied` |
| `safety.claim_count` | parent `claim_write_scope` tool starts |

Do not reimplement the fence in Python. A denied event is the durable fact.
Unauthorized writes that the runtime failed to record are a runtime bug, not
an eval gap.

Pointers (private control plane + in-repo evals):

- ownership: `$CONTROL_ROOT/ownership-final/cases` (DJ, OV, PF, …)
- sandbox: `docs/C2_3C_S_EVAL_SANDBOX_INTEGRITY.md` and `evals/` navigation cases
- permission: `evals/scenarios/permission/`
