3. 问题与修复

W01 · Console Host 空闲提示缺 文

基线：Windows Terminal 完整；Console Host 显示 @ 件。原生 Write-Host "@ 文件" 正常，排除字体缺字。

根因：独立 ratatui/crossterm 探针证明，长样式行中的 U+00B7 · 被 ConHost 按宽字形绘制，但布局只计 1 列；累计偏移后后续 CJK 字形被空格覆盖。改为 | 或只替换第一个 · 即恢复完整。

修复：Windows 空闲提示使用 | ；非 Windows 保留 · 。新增 Windows 断言。

/ 命令 | ! Shell | @ 文件 | Shift+Tab 权限 | Alt+V 粘贴 | Ctrl+? 快捷键
W01 独立 ConHost 探针证据

W02 / W06 · 布局、resize、滚动与残影

实测 120×30 → 80×24 → 100×30 → 130×30 → 133×33 → 120×30；TUI 日志确认收到真实 cells 尺寸。80×24 压缩布局、隐藏 mascot、footer 不溢出；最大化后回到 120×30 无可见残影。

W03 · 欢迎吉祥物与无块状回退

删除 brand.rs 与块状字符画回退；无原生图片时欢迎页只显示文本并回收列宽。Windows Terminal 通过 WT_SESSION + DA1 ESC[?61;4;...c 双重确认 Sixel；探针有界（150 ms），源图最大 512 px；Sixel 清理不越界发送。

ConHost 无 Sixel 时隐藏图片；80×24 高度不足时隐藏图片且不留块状占位。

W04 · 友好路径展示

新增 leveler-core::path::display_path：仅展示层去掉 \\?\（drive/UNC），保留 device/incomplete 路径；操作路径、身份校验与子进程参数不变。接入 doctor、状态行、外部会话 cwd、工具摘要、完整输出错误、skills/problem、导出 toast。

doctor 实际输出：repo: C:\...、config: C:\...；测试覆盖 \\?\C:\、\\?\UNC\、Volume{...}、GLOBALROOT、不完整路径与普通路径。

观察（未作为 W08 依据）：CLI doctor 在该测试 shell 的默认 sandbox 工具探测中报告 git/cargo 不在 PATH，而 where.exe 能看到两者；TUI full-access 工具与 dogfood 的 cargo/git 调用均成功。疑似 low-integrity sandbox 探测，未在本次 TUI 修复范围内继续定位。

W07 · 输入、IME、快捷键与粘贴

Windows Terminal 原生 Ctrl+V 会把换行变为 Enter、非 BMP emoji 变为 ?；剪贴板本身正确。这是宿主输入限制，不是 CodeLeveler 剪贴板读取；Alt+V 为应用层替代，已写入 USAGE。

W09 · Windows 控制台代码页解码

合法 UTF-8 原样返回；Windows 非法 UTF-8 使用 GetConsoleOutputCP()，当其为 0/65001 时回退 GetOEMCP()，再用 MultiByteToWideChar 两阶段解码。接入模型工具实时/最终输出、后台日志、用户 shell 完成捕获和 TUI 完整输出。

用户 shell 保留原始 combined.log 为权威，另写解码 combined.utf8.log；TUI 优先读取 UTF-8 sidecar。
