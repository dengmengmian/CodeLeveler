# CodeLeveler 1.0.20

[中文](RELEASE.zh-CN.md) · [Version history](../CHANGELOG.md)

This release improves local commands and conversation readability in the terminal.

- **Shell Mode:** type `!` in an empty input to enter command mode; Tab completes files, directories, and commands.
- **Full output:** each command shows its status and output in the conversation. Use `/output` to read the full result and `/copy output` to copy it.
- **Background work:** `Ctrl+B` moves a running command to the background; `Ctrl+C` stops the current command. Background tasks can also be stopped individually.
- **Clearer conversations:** user messages have a full-width background, long output can collapse, and copying preserves only the original text.

See the [home page](../README.md) for installation and updates, and the [changelog](../CHANGELOG.md) for unreleased changes.
