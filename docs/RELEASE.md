# CodeLeveler 1.0.26

[中文](RELEASE.zh-CN.md) · [Version history](../CHANGELOG.md)

This release adds cross-session memory as an opt-in capability: the runtime captures durable facts after a turn settles, consolidates them into Markdown topics, and gives the model a bounded index it can read in later sessions. Memory is off by default, never blocks the turn, and never decides what the agent does next. The release also reconciles a blocked goal against the model's own open plan, gives plan progress a dedicated status row, and fixes capture lifecycle and dependency issues found during qualification.

- **Cross-session memory, off by default.** `[memory].rollout` is `off`, `record_only`, `shadow` or `active`. Only `active` exposes memory to the model; `off` opens no database and creates no directory. A workspace's identity is its git remote, so two clones of the same repository share memory, while a temporary working directory has no workspace scope. Everything lives under `<LevelerHome>/memory/`, never in the repository.
- **Capture is durable and asynchronous.** After every settled turn the runtime queues the ranges the session has not captured yet. Extraction runs as a background job with a five-minute lease and a forced tool call, and writes structured observations as Markdown files plus a SQLite ledger row. Capture never touches the conversation and never blocks the turn; a memory failure is reported as activity after the user's work already succeeded. Committing an outcome is idempotent.
- **Restarts and quits do not lose work.** A normal quit releases an in-flight capture as retryable without charging the bounded retry budget, and the next startup scans the workspace queue and resumes claimable jobs without enqueuing historical turns. A paused session or a global `off` rollout records the skipped turns, so re-enabling memory does not backfill them. A crashed process's job waits for its lease instead of being stolen.
- **Dream consolidates with one owner.** Dream reads pending observations and creates or updates Markdown topics. A durable row in `memory_state.sqlite` serializes consolidation across processes with a six-hour lease; a lease whose owner PID is gone is treated as expired. Automatic Dream runs after capture settles, `/dream` runs one pass, and `D` runs a bounded batch with call and byte budgets.
- **Reading and managing memory.** The prompt receives a bounded `## Cross-session memory` index of topic paths and one-line descriptions; the agent reads a topic with the ordinary `read_file` tool. There is no retrieval API and no vector database. `/memory` opens a page for both scopes with read, filter, refresh, pause and Dream keys; `leveler memory status|show|remember|forget` covers the CLI. Forget binds to the exact BLAKE3 hash printed by `memory show`: a tombstone is written first, the file is removed, and the path is excluded from the index, capture and consolidation. The retained archive is invisible to the agent's file tools, so a forgotten fact cannot be recalled from it.
- **A blocked goal must agree with its plan.** A `blocked` resolution is refused once while the model's own latest explicit plan still lists steps it never marked completed. The refusal names the open steps and every structured exit; a confirmed block is accepted with the conflict kept in its receipt. The check is bounded once per drive, never rewrites a block into a completion, and never marks pending steps done on the model's behalf.
- **Tool input mistakes are named.** `shell_command` refuses `program`, `args` or `command` used beside or instead of `cmd`, names a wrong-typed `cmd`, and never executes a refused call. Descriptive extras such as `reason` and the documented `workdir` alias keep working.
- **Plan progress has its own row and updates in place.** A running plan is shown continuously in the TUI status area instead of only at the moment a step changes.
- **Sub-agent nesting is stack-bounded.** Child run futures are boxed, so polling a nested state machine no longer costs another full stack frame per nesting level.
- **Evaluation attribution.** A completion claim the runtime refused for a named reason is recorded with that detail and is no longer booked as a runtime gate failure; a run is judged by its trajectory.
- **Dependencies.** `quinn-udp` 0.5.16 closes RUSTSEC-2026-0538.
- **Project.** Added GitHub issue forms.

The release archive is the command-line program for macOS (Apple Silicon and Intel), 64-bit Linux, and 64-bit Windows. There is no Linux ARM archive. The desktop client can be built from source and is not in this archive. Packages are not Apple-notarized or Microsoft-signed.
