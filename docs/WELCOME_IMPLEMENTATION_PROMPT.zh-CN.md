# CodeLeveler 欢迎页实施提示词

以下内容可直接复制给 Codex。布局截图仅作参考，图片素材使用指定的本地 PNG。

---

请在 `CodeLeveler` 仓库中完成 TUI 欢迎页改版。

先阅读仓库 AGENTS.md，检查 Git 工作区、现有启动页、主题、会话空态、输入框和鼠标命中逻辑，确认图像渲染方式再修改。保留所有已有未提交改动，不创建分支、不提交、不安装或重启应用。仅改动欢迎页、必要的交互接入、品牌资源和相应测试；不要顺带重构或升级依赖。

使用 `codeleveler.png` 作为正式品牌吉祥物；如果仓库已有 `assets/brand/codeleveler-mascot.png`，优先核对并复用。将原始 PNG 原样纳入资源目录，保留真实透明通道，不能用聊天截图、网页截图或参考图中的其他产品吉祥物作为素材，也不要重新生成或重画吉祥物。

按用户确认的双栏欢迎界面布局：顶部左侧为水獭，右侧为 CodeLeveler 和版本；品牌说明为“让每个模型发挥最大能力”，下一行为“准备就绪，描述你的目标即可开始”。保留当前已经缩小的原图尺寸上限（22 列、按比例约 7 行），不重新放大。分隔线下左侧为一条已实现功能的提示及一句说明，右侧为三个现有功能入口，依次为：

1. 历史会话（复用 `/sessions`）
2. 查看帮助（复用 `/help`）
3. 选择模型（复用 `/model`）

点击入口或使用 Alt+1/2/3，打开相应的现有界面，复用其真实命令处理及可用性规则，不通过覆盖输入框来伪造操作。不发起模型对话，不覆盖已有草稿或附件。弹层、侧会话及非欢迎页不会误触。菜单行使用卡片底色，不加高亮背景，不添加底部“点击或 Alt+1/2/3……”提示，也不保留旧的“从当前项目开始”标题。英文界面提供对应英文文案。此次只接入已有功能，不新增“继续上次会话”或“查看更新记录”。

左侧提示仅从经过确认的已有功能中选取，例如 `/goal` 及其目标执行说明。每次启动选择一条，同一次运行中重绘、缩放或切换页面时保持稳定，不实时生成文案、不每帧轮换，不虚构“新功能”或版本发布信息。

吉祥物必须显示原始透明 PNG 的细节，不要转成彩色字符图、半块字符图或 ASCII 图。先检查现有 Ratatui 图像通道，必要时使用与现有 Ratatui 版本兼容的图像组件。在确认支持原生图像的终端中显示 PNG，保持比例与透明背景；不支持或无法可靠确认的终端、NO_COLOR 和过窄窗口使用现有阶梯 Logo。不要默认所有终端都能显示 PNG，不要把终端协议控制序列混入普通文字行。复用绘制与清理生命周期，保证第一条消息、弹层、切换页面、窗口缩放、暂停恢复和退出时图片不会残留或盖住输入框。不要让图像能力探测抢占现有终端输入读取，也不要每帧解码 PNG 或启动外部进程。

宽终端将功能提示与操作入口左右分栏；窄终端上下堆叠。命中区域与渲染共用同一布局，左侧提示不能误触右侧入口。按可用空间缩小或切换为终端 Logo，保证品牌和入口可用、不横向溢出。短终端优先保留操作信息。宽度计算使用终端显示列宽，检查中文、长路径、窗口缩放、深浅主题和无彩色模式。保留已有未信任配置提示。欢迎页仅在没有真实对话时出现，第一条真实消息后隐藏，恢复历史会话不闪回欢迎页。

测试必须覆盖：三个入口打开正确的现有界面且不发送对话、已有草稿及附件保护、弹层及非欢迎页不会触发、提示在一次运行中稳定、宽窄布局和命中位置一致、透明 PNG、终端不支持图像时的降级、首条消息隐藏和图像生命周期。按仓库要求先锁定行为再实现，运行与本次修改相关的最小充分测试。最后生成一张完成示例图，必须展示原图效果；如图片是按真实布局合成的离屏预览而非真实终端截图，要明确标注。报告实际测试结果与未验证的真实终端行为，不要把设计稿当作程序截图交付。
