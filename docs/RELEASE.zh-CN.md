# CodeLeveler 1.0.13

英文版：[`RELEASE.md`](RELEASE.md)

这个补丁重点改善 CLI/TUI 与 Agent Core 的可靠性和终端性能。
Web、Desktop 不属于本次发布资格范围。

## 终端

- 代码块全文可通过对话滚动访问，覆盖长代码块、窗口调整与历史恢复。工具输出可通过键盘访问，Ctrl+O 展开当前可见的探索摘要，而不只是切换隐藏成员。
- 流式语法高亮复用完整行的 Syntect 状态；未完成行从已保存状态重新高亮，保留跨行语法正确性和完整代码文本。
- 有界高亮缓存从 512 项调整为 640 项，解决已测量的 574 代码块历史场景。既有源码字节预算和 LRU 驱逐策略保持不变。
- 失败回合与持久化取消显示为终态；重复取消会等待，不再承诺强制操作。
- 标准输入或输出不是终端时，TUI 在进入 raw mode 前明确返回不支持的终端错误。

## Runtime 与上下文

- Auto 权限判断按 Windows 引号与 `^` 转义规则检查 `cmd.exe` 的字面重定向目标；Full 仍完全放开。
- 取得写入范围前的进程和显式受限写入不再隐式获得共享临时目录的写权限；普通 Auto 临时写入仍可用，Full 不受限制。
- 交互命令在持久化应用后才确认；取消在确认前持久化，中断后通过恢复流程核对终态。
- Goal 恢复从带隔离约束的持久化回合事实恢复中断谱系，普通续接通过既有 Runtime Owner 处理。
- 软压缩阈值按有效输入容量的百分比计算，默认值为 95%。恢复会话或调整策略后，终端上下文利用率使用 Runtime 的计量。

## 验证与限制

代码全文可见性覆盖窗口调整与历史重放回归。受控 Agent Fixture 校验 Goal 闭环，明确区分连续性与任务完成。独立性能对照使用相同代码语料和终端尺寸，并包括真实 PTY 与新执行的 600 秒压力测试。

增量高亮减少流式输出中的重复工作，Markdown 仍执行整篇解析。实测机器上，1MB 代码冷高亮仍约需一秒。PTY 测试没有验证物理终端合成器的闪屏表现。
