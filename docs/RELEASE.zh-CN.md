# CodeLeveler 1.0.26

[English](RELEASE.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版新增跨会话记忆，作为默认关闭的可选能力：运行时会话结算后捕获持久事实，整理为 Markdown 主题，并在后续会话中向模型提供有界的主题索引。记忆默认关闭，不阻塞回合，也从不决定 Agent 的下一步动作。本版同时让被阻塞的 Goal 与模型自己的未完成计划对账，为计划进度增加独立状态行，并修复资质验证中发现的捕获生命周期与依赖问题。

- **跨会话记忆，默认关闭。** `[memory].rollout` 为 `off`、`record_only`、`shadow` 或 `active`；只有 `active` 会把记忆暴露给模型，`off` 不打开数据库、不创建目录。工作区身份取自 git remote，因此同一仓库的两个克隆共享记忆，而临时工作目录没有工作区作用域。所有数据位于 `<LevelerHome>/memory/`，不写入仓库。
- **捕获是持久且异步的。** 每个已结算回合后，运行时把该会话尚未捕获的范围排入队列。抽取作为后台任务运行，持有五分钟租约并强制使用工具调用，产出结构化 observation 的 Markdown 文件与 SQLite 账本行。捕获不触碰对话、不阻塞回合；记忆失败在用户工作已经成功之后以活动状态报告。结果提交是幂等的。
- **重启与退出不丢工作。** 正常退出把进行中的捕获释放为可重试，且不消耗有限的失败预算；下一次启动扫描工作区队列并恢复可认领的任务，不回填历史回合。会话暂停或全局 `off` 会记录被跳过的回合，重新启用记忆时不会补抓。崩溃进程的任务等待租约到期，不会被其他进程抢占。
- **Dream 只有一个所有者。** Dream 读取待处理 observation，创建或更新 Markdown 主题。`memory_state.sqlite` 中的持久行以六小时租约跨进程串行化整理；所有者 PID 已消失的租约视为过期。自动 Dream 在捕获结算后运行，`/dream` 运行单次整理，`D` 运行受调用数与字节预算约束的批量整理。
- **读取与管理。** 每回合的提示词收到有界的 `## Cross-session memory` 索引，列出主题路径与一行描述；Agent 用普通 `read_file` 读取主题。没有独立检索 API，也没有向量数据库。`/memory` 页面覆盖两个作用域，支持阅读、过滤、刷新、暂停与 Dream 操作；`leveler memory status|show|remember|forget` 提供 CLI。忘记绑定 `memory show` 打印的精确 BLAKE3 哈希：先写 tombstone，再删除文件，并从索引、捕获与整理中排除该路径。保留的 archive 对 Agent 文件工具不可见，被忘记的事实无法从中召回。
- **被阻塞的 Goal 必须与计划一致。** 模型自己最新的显式计划仍列出从未标记完成的步骤时，`blocked` 结案会被拒绝一次；拒绝会列出未完成步骤与所有结构化出口，确认后的阻塞会被接受，冲突保留在回执中。该检查每个驱动周期最多一次，永不把阻塞改写为完成，也永不代替模型把待办步骤标记为完成。
- **工具输入错误会被点名。** `shell_command` 拒绝与 `cmd` 并列或替代 `cmd` 的 `program`、`args`、`command`，会指出类型错误的 `cmd`，被拒绝的调用不会执行。`reason` 等描述性字段与文档化的 `workdir` 别名保持可用。
- **计划进度有独立状态行并原地更新。** 运行中的计划持续显示在 TUI 状态区域，而不是只在步骤变化时出现一次。
- **子代理嵌套受栈约束。** 子代理 run future 被装箱，轮询嵌套状态机不再为每一层嵌套多消耗一个完整栈帧。
- **评测归因。** 被运行时按明确原因拒绝的完成声明会连同该原因记录，不再被记为运行时 Gate 失败；一次运行按其轨迹判定。
- **依赖。** `quinn-udp` 0.5.16 关闭 RUSTSEC-2026-0538。
- **工程。** 新增 GitHub issue forms。

安装包是命令行程序，包含 macOS（Apple Silicon 与 Intel）、64 位 Linux 和 64 位 Windows。没有 Linux ARM 安装包。桌面客户端可从源码构建，不在本安装包内。安装包不含 Apple 公证或 Microsoft 签名。
