# CodeLeveler 1.0.23

[English](RELEASE.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版让重连与崩溃恢复以证据为准：CodeLeveler 无法证明发生了什么时，会如实说明，而不是猜测。

- **重连**：后台会报告正在服务本会话的构建，以及重连前后进程是否更换。版本不一致会持续显示为问题；运行中的任务只会被如实描述为可能已中断或状态未知，没有证据时不会声称它已经停止；连接断开时，输入内容和审批选择会保留。
- **崩溃恢复**：上次运行中断、且部分工具调用没有记录结果时，回合会暂停而不是自动重试。`/recover` 会列出每个调用的状态——已中断、状态未知，或审批中被打断、操作未执行；确认后只会把它们记为「结果未知、未重放」，不会重放，也不代表调用成功。
- **消息**：提交的消息会显示是否送达、被拒绝（内容恢复到输入框）或无法确认；处理它的进程已退出时不会自动重试。
- **后台任务**：状态区分「随后台进程中断」「状态未知」「标识冲突」与真正运行中或已结束，不再把无法证明的状态说成某一种结论。
- **输入**：`→` 可以像 `Tab` 一样接受输入框里的灰色下一步建议；建议变成可编辑内容，光标落在末尾，只有按 Enter 才会发送。没有建议显示时，它仍然是普通的光标右移。
- **目标**：目标核算能识别显式的单字母字段标记，同时仍拒绝偶然出现在叙述里的字母和仅作证据引用的提及。

安装包是命令行程序，包含 macOS（Apple Silicon 与 Intel）、64 位 Linux 和 64 位 Windows。没有 Linux ARM 安装包。桌面客户端可从源码构建，不在本安装包内。安装包不含 Apple 公证或 Microsoft 签名。已有配置可以继续使用。
