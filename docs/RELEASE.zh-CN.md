# CodeLeveler 1.0.21

[English](RELEASE.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版让思考记录留在产生它的模型上，记忆可以查看和管理，目标完成以请求和证据为准。

- **思考记录**：历史思考只回传给产生它的路线，且该路线必须声明对应模式。切换模型不会把一个模型的私有推理混进另一个模型。产品已经排除的旧模型版本仍然排除。
- **目标**：任务完成后的追问仍是普通对话；目标结束后会话回到普通对话。完成判断看仍然有效的请求和证据。仅被允许、并未要求的路径不算必须交付的产物。验收被拒绝后可以继续恢复，不必从头开始。
- **记忆**：`/memory` 可搜索、查看和管理记录，`/memory status` 查看处理状态。用户事实与实验性经验记录分开设置，经验记录默认关闭。召回的用户事实保留来源和权威。历史敏感记录不出现在界面和日志里。
- **会话与终端**：项目规则随会话加载，暂停的工作可以继续。本地终端保留自己的输出、所属进程和文件描述符。

安装包是命令行程序，包含 macOS（Apple Silicon 与 Intel）、64 位 Linux 和 64 位 Windows。没有 Linux ARM 安装包。桌面客户端可从源码构建，不在本安装包内。安装包不含 Apple 公证或 Microsoft 签名。已有配置可以继续使用；新的经验记录在显式开启前保持关闭。

安装和更新见[首页](../README.zh-CN.md)。版本历史见[更新日志](../CHANGELOG.zh-CN.md)。
