# CodeLeveler 1.0.27

[English](RELEASE.md) · [文档索引](README.zh-CN.md) · [历史版本](../CHANGELOG.zh-CN.md)

1.0.27 默认开启跨会话记忆。后台测试的结果现在会对应到它实际跑过的工作区版本。终端也能持续显示计划进度，并修复了 Windows 上部分输出乱码。

## 跨会话记忆

输入 `/memory` 查看全局和当前工作区的笔记。页面支持搜索和侧栏预览，按 `Ctrl+F` 可全屏阅读。`/dream` 整理一次，记忆页的 `D` 批量整理。也可以用 `leveler memory status|show|remember|forget` 管理笔记。

程序在回合结束后从对话里提取笔记，后台再把笔记整理成 Markdown 主题。后续会话只带一份有限长度的索引，模型用 `read_file` 打开需要的主题。笔记存在 `<LevelerHome>/memory/`。使用同一 Git 远端的克隆共享工作区笔记，临时目录只有全局记忆。

正常退出时，正在提取的任务会留到下次重试，且不扣重试次数。进程崩溃时，任务需等五分钟租约到期后才能重新认领。整理工作同时只由一个进程负责。其六小时租约在持有进程消失后会立即视为过期。

在配置中设 `rollout = "off"` 可以关闭自动记忆。`record_only` 和 `shadow` 的具体行为见[记忆指南](MEMORY.zh-CN.md)。暂停期间及关闭自动记忆时结束的回合，之后不会补抓。`memory` 和 `memory_model` 变更在重载后生效。用 `forget` 删除时要填写预览时显示的 BLAKE3 哈希。删除记录会防止该路径被重新加入索引，模型也无法从归档里读取旧内容。

## Goal 和验证结果

- `tests` 或 `command` 按声明里的完整命令查执行记录。同一命令以最后一次为准。`tests` 显示 `verified` 时，表示那条命令在最后一次变更后运行并以 0 退出。测试数量和覆盖率需要另查测试输出。
- 后台命令只有在启动和结束处于同一工作区版本，且该版本仍满足完成判定时，才可作为当前证据。运行期间有改动时，退出状态仍保留，验收需要在当前版本重新跑。旧记录缺少启动版本时也需要重跑。
- 后台任务确实改过文件时，只给工作区版本计一次变更。自动通知、`wait_task` 和 `get_task` 都读取同一条记录。失败或停止的任务发生了写入也会计入。
- `named` 交付由模型判断时记为 `reported`。缺少必要证据的需求仍为 `unverified`，并显示警告。详情见 [Goal 范围契约](GOAL_SCOPE.zh-CN.md)。
- 模型声明 `blocked` 时，如果自己的计划还有没标完成的步骤，运行时会提醒一次，并列出这些步骤。再次确认后可以结案，冲突会留在记录中。
- 评测会记录运行时拒绝完成声明的具体原因，按实际过程判定结果。

## 界面、工具和修复

- 计划进度有独立的终端状态行，步骤变化时在原位置更新。后台任务启动时只显示一处提示，失败可以在对话和后台任务页查看。运行计数只包含当前仍在运行的任务。
- Windows 子进程和后台日志现在能正确拼接被管道切开的多字节字符。完整输出页优先读取 UTF-8 展示副本，原始 stdout 和 stderr 文件保留原始字节。Shell 在启动前被拒绝时，实时界面会直接显示原因。
- `shell_command` 用 `cmd` 接收命令。如果传了 `program`、`args`、`command`，或者 `cmd` 类型不对，调用会报出具体参数并拒绝执行。`reason` 和 `workdir` 仍可用。
- 嵌套子 Agent 降低了运行时的栈占用。依赖 `quinn-udp` 升至 0.5.16，修复 RUSTSEC-2026-0538。GitHub 新增了 Issue 表单。

本版命令行安装包支持 macOS（Apple Silicon、Intel）、Linux x86_64 和 Windows x86_64。桌面客户端需从源码构建。安装包未经过 Apple 公证或 Microsoft 签名。安装和更新见[首页](../README.zh-CN.md)。
