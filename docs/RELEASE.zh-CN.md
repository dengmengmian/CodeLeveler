# CodeLeveler 1.0.20

[English](RELEASE.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版改进终端中的本地命令和会话阅读体验。

- **Shell Mode**：空输入框输入 `!` 进入命令模式，Tab 补全文件、目录和命令。
- **完整输出**：每条命令在会话中显示状态和输出，使用 `/output` 查看完整结果，`/copy output` 复制。
- **后台运行**：`Ctrl+B` 将正在执行的命令转入后台，`Ctrl+C` 停止当前命令；后台任务也可以单独停止。
- **更清晰的对话**：用户消息使用整行背景，长输出可折叠，复制时只保留原文。

安装和更新见[首页](../README.zh-CN.md)。尚未发布的改动见[更新日志](../CHANGELOG.zh-CN.md)。
