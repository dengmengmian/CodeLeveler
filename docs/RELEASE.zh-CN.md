# CodeLeveler 1.0.22

[English](RELEASE.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版退役记忆系统，让配置成为可热更新的运行时状态，并把用户要求的暂停当作运行时必须遵守的边界。

- **记忆**：Memory 2.0 退役。后台提取、存储与检索、上下文注入、相关工具、`/memory` 命令与管理界面均已移除。会话历史、恢复、压缩、目标、计划与项目规则保持不变；已有数据库升级时删除记忆队列及专属配置列。
- **配置**：修改 `~/.leveler/config.toml`（或仓库配置包）后在下一轮对话生效，无需重启；`/reload` 立即重新读取。正在执行的任务沿用开始时的模型与服务商，`/model` 的显式选择保持固定。文件写入不完整时保留上一版可用配置并说明原因。
- **目标与计划**：「阶段 1 完成后停下，等我确认」会让回合正常结束、阶段 2 保持 `pending`，并能跨 Resume 与 Compaction 保持。计划进度只统计当前计划。用问句提出的执行请求同样有效。计划仍有未完成步骤时，Chat 回合会说明这一点，而不是静默结束。
- **上下文与用量**：`/context` 与 `/usage` 是同一个页面，`/trace`、`/context`、`/usage` 在 Agent 执行期间也能打开。用量来自运行时持久化的模型调用记录；Provider 未返回用量、未配置价格或只有部分请求有价格时，不会显示成 `$0.00`。
- **终端**：40 列及以下终端打开 `/` 命令菜单不再崩溃；提交目标不再被描述为任务委托。
- **欢迎页**：空会话打开时显示欢迎卡片，包含品牌标识、点名常用命令的简短提示，以及可点击的「历史会话 / 查看帮助 / 选择模型」。会话一旦有内容就自动让位。

安装包是命令行程序，包含 macOS（Apple Silicon 与 Intel）、64 位 Linux 和 64 位 Windows。没有 Linux ARM 安装包。桌面客户端可从源码构建，不在本安装包内。安装包不含 Apple 公证或 Microsoft 签名。已有配置可以继续使用。`/develop` 命令已移除，显式目标执行统一使用 `/goal`。

安装和更新见[首页](../README.zh-CN.md)。版本历史见[更新日志](../CHANGELOG.zh-CN.md)。
