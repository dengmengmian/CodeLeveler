# CodeLeveler 1.0.20

英文版：[`RELEASE.md`](RELEASE.md)

终端的本地命令成为完整界面：`!` 进入真正的 Shell Mode，每条命令保留完整输出，
运行中的命令可以带着原进程转入后台。用户消息也收敛为一条铺满阅读宽度的背景带。

## Shell Mode

- 空输入框中的 `!` 是模式标记，不是命令文本。该模式有自己的提示符与强调色。
- 离线 Tab 补全覆盖文件、目录与 PATH 可执行文件。歧义匹配打开可滚动的候选菜单，支持键盘、指针与滚轮；接受候选不会执行命令。
- 每条命令是一条行内记录，包含状态栏、`$ command`、stdout/stderr 来源、实时尾部与实测耗时。已结束的长结果保留命名折叠，按需完整展开。
- 记录行与实时活动行都可点击停止。`Ctrl+C` 精确取消该次执行；`Esc` 与 `Ctrl+B` 不会。

## 完整输出

- 完整的 stdout/stderr 与按到达顺序合并的流都会保留，而不是有损的 1 MiB 尾部。
- `/output` 分页打开完整结果；`/copy output` 干净复制。大结果与小结果的每帧成本相同。
- 可选中并复制原始行，保留制表符、软换行重新拼接。

## 后台交接

- `Ctrl+B` 把运行中的命令交给既有后台注册表，执行 id、进程与进程组保持不变。不会重新拉起或重跑：输出、退出码与耗时保持连续。
- 交接可持久化。冷恢复会报告已完成执行，或把没有终态事实的孤儿报告为 unknown——绝不会报告为仍在运行。

## 会话背景带

- 用户消息是一整条铺满阅读宽度的背景带。深色主题使用现有 `#171A1E` 色阶（主背景 `#111315`）；浅色主题 `#FFFFFF`，高对比 `#1A1A1A`。
- 柔和蓝色 `❯` 位于首行，正文保持主色，短消息与长消息共享相同的左右边界。背景带高度只随消息增长，不显示身份文字、边框、分割线或额外垂直内边距。
- 选中背景带复制时仍只得到原始文本。背景、标记、状态栏与其它绘制字形不会进入剪贴板。

## 修复

- 后台等待行的标记在等待目标运行时使用共享的 120ms 旋转动画；减少动态效果时保持静态。
