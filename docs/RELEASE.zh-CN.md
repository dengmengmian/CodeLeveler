# CodeLeveler 1.0.14

英文版：[`RELEASE.md`](RELEASE.md)

这个补丁把终端变成一个以原语为先的编辑面——输入编辑、历史与帮助搜索、本地终端
诊断，以及带证据的剪贴板路由——并把会话展示改成不再重复对话里已经写明的东西。
Web、Desktop 不属于本次发布资格范围。

## 终端

- 输入框有有界的编辑历史。Ctrl+Z 撤销，Ctrl+Shift+Z / Alt+Z 重做，Ctrl+Y 恢复最近删掉的文字。混合粘贴及其文件引用、图片附件绑定会一起恢复；提交或切换会话结束草稿历史。每个栈最多 100 条、8 MiB。
- Ctrl+R 搜索已提交的输入历史。Enter 把选中项放回草稿供编辑而不发送；Esc 或 Ctrl+C 关闭搜索并保留原草稿。
- `/help` 可搜索。输入即过滤命令、快捷键与说明，↑/↓ 选择，窄宽度下选中行仍然可见。
- `/doctor` 打开本地终端诊断，`leveler doctor` 输出同一批观测：终端、SSH/tmux、颜色提示、换行键与剪贴板路由。诊断不读写剪贴板，也不改动终端设置；没有证据的能力保持 unknown。
- 复制选中的对话文本优先使用 native 剪贴板并读回校验，且仅在本地非 tmux 环境。SSH 跳过远端 native 剪贴板；tmux 同样跳过 native 写入，因为继承的 server 环境无法确定当前连接的客户端；两者改为写入 tmux 粘贴缓冲并发送 OSC 52。缓冲写入或转发序列报告为已发送但本地投递未校验，超过 64 KiB 的 OSC 52 负载会被明确拒绝。
- 命令在对话里保留完整身份，展开后按终端宽度换行显示完整参数；状态条显示阶段与命令自己的耗时，不再重复命令名。命令在等待且尚无输出时会明确说明。
- 后台任务页把任务列表固定在详情面板上方：身份与停止控件保持固定，仅命令/日志内容滚动；鼠标点击选中任务，滚轮按指针所在区域分发，每个任务保留各自的滚动与跟随状态。

## 展示

- 底部上下文条只做展示。百分比、分母、条长与颜色都来自 runtime 投影；provider usage 仅作为无快照时的兜底，窗口未知的快照不出仪表。八格仪表在 70% 以下用 info，70–89% 用 warning，90% 及以上用 error。窄行依次丢弃仪表、缓存与容量 chip，时钟与权限 / 协作控件优先保留。
- `/context` 分别命名输入容量、模型窗口与输出预留。压缩策略与阈值仍留在输入容量轴上，而 runtime 快照的 `free_tokens` 仍表示模型窗口的空闲；检查器按选中的轴推导网格与空闲余量。
- 运行中命令的状态显示阶段与命令自己的耗时，因此命令名只在其对话行里陈述一次。
- 思考使用有界预览。进行中的思考显示标题与最近三行正文；已结束的独立思考在显式展开前不占历史行，正文为空的已结束思考保持隐藏。手动展开的思考不会被后续事件关闭，`Ctrl+O` 展开最新工具组，没有工具组时展开最新思考。
- 探索回执在每一层独立折叠：展开回执按真实时间顺序还原工具标题，但不显示已结束的思考；关闭父级会隐藏全部子项，同时保留读者显式的展开选择；每个工具复用各自的展开状态。
- 真实会话从视口顶部开始，因此流式输出与思考折叠不会移动第一条消息；只有空会话的启动卡居中。手动折叠，以及 runtime 完成或中断触发的思考折叠与回执重分组，都会保持视口顶行不动。
- 命令详情仍可在原位访问，后台命令在进程退出时会结算自己的行。

## 验证与限制

输入编辑、搜索、诊断与剪贴板路径都有确定性覆盖，包括有界历史、字素安全恢复与路由回执。会话展示覆盖窗口调整、历史重放与 PTY 驱动的 dogfood fixture，上下文统计 fixture 语料库固定了新的底栏轴。

剪贴板路由证据刻意收窄：只有本地非 tmux 环境下的 native 写入加读回一致才算已校验，tmux 配置永不被静默修改，DCS passthrough 支持仍为 unknown。物理终端合成器闪屏与真实远端终端剪贴板投递不在这些测试的资格范围内。
