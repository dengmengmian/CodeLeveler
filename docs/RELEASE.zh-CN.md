# CodeLeveler 1.0.29

[English](RELEASE.md) · [文档索引](README.zh-CN.md) · [历史版本](../CHANGELOG.zh-CN.md)

本版让项目信任与技能在终端内可操作，`AGENTS.md` 成为标准项目上下文，所有独立 TUI 页面统一到一套设计系统，并加固 Runtime 退出与执行所有权。

## 信任与项目上下文

- `/trust` 成为信任的原生入口。它复用 CLI 的同一份 Store 与发现逻辑，查看全部、未信任、已信任和已变化的定义，显示内容、展示过的 SHA-256、批准版本以及“已批准 → 当前”的差异，并支持单个或批量标记授权、撤销。页面不会把命令交给模型，也不会通过 Shell 执行 CLI。运行中的 `load_skill` 遇到未信任技能时发出类型化请求（仅本次允许 / 信任当前内容版本 / 拒绝），决定后原工具调用继续。仅本次允许不写记录；拒绝按该身份与摘要在本会话内记住；断连或取消时安全拒绝，不会挂死。FullAccess 只采纳会话创建时、首个模型调用之前捕获的规则与技能字节；基线之后的编辑、没有可信来源的 Resume 会话以及声明式 Agent 定义仍需持久批准。
- `AGENTS.md` 成为标准项目上下文。任意层级的 `AGENTS.md` 在 Auto、Restricted 与 Full 默认加载，不再需要信任批准；首次创建、内容编辑、`git pull`、配置变化、Resume 与嵌套目录范围都直接生效。它是上下文而不是授权：不能授予 Shell、网络、文件系统或外部路径权限，不能修改权限模式，不能写入、批准或撤销 Trust 记录，也不能让其他定义变成已信任。加载器仍强制普通文件、UTF-8、路径包含与符号链接边界。`.leveler/instructions.md`、`.leveler/rules/*.md`、声明式 Agent 与技能仍受信任门禁。既有 `AGENTS.md` 信任记录保留但不再读取；启动不再打印定义列表或信任提示。

## 技能

- `/skills` 成为技能的统一入口。它读取 Runtime、`$` 弹窗与 `load_skill` 使用的同一份注册表：可用、已禁用、未信任与无效状态，搜索与筛选，带来源和调用开关的详情，以及通过 `state/skills.toml` 持久启停；项目级停用按规范化项目根区分。技能以 `/name [args]` 调用；当裸名称会占用内置命令时使用 `/scope:name [args]`。每回合记录哪些技能被索引、选中、加载和拒绝，不记录正文或文件路径。`load_skill` 与显式调用会校验包并交付参考文件清单；在该回合内，`read_file` 可以按页读取清单中的参考文件，且只提供本次交付的精确包版本；普通路径读取 `SKILL.md` 与未绑定参考仍然被拒绝。

## 终端界面

- 28 个独立页面统一到一套模态工作区：一致的几何、标题、页脚、焦点、鼠标路由与页级列表导航。列表页共享行、选择与悬停模型；分栏页在窄屏按规则回退；文档页使用完整可用高度；输出查看器按窗口显示大型文件内容；Memory 与 BTW 保留独立 Surface，但使用同一套视觉语言。完成的回复提供 `[Copy Markdown]` 与 `[Copy Text]`。恢复后的检查点回退会一致显示被回滚的对话；损坏的恢复快照不再被误报为空候选。

## Runtime 与所有权

- 不再发送请求的 Unix IPC 连接无法继续占住优雅退出与空闲回收。新版本启动时会等待旧的或忙碌的 Runtime 安全退出，而不是直接失败。`leveler runtime status` 显示工作区 Runtime 的身份、构建、工作计数与空闲回收状态；`leveler runtime stop` 只会在不会打断工作时请求正常退出，无法安全退出时给出原因并返回非零。用户 Shell 的终态事件只在其持久所有权令牌释放之后发布，输入框不再可能把输入送进仍持有活动回合的会话。`leveler background logs` 对宿主任务读取宿主记录，而不是打印空的库存尾巴。

## 行为变化与升级说明

- `AGENTS.md` 不再需要批准；旧记录保留在磁盘上但不再读取。未信任技能在做出决定前仍不会加载，但 `load_skill` 现在会发起请求，而不是静默跳过。通过 `read_file` 读取技能参考只限于该回合交付的精确包版本。1.0.28 及之后的客户端升级交接不变；由 1.0.28 之前的版本启动的 Runtime 不认识访问令牌握手，请让它完成当前工作并正常退出一次后再启动本版本。客户端不会向它发送信号或抢占端点。

## 已知限制

- 本轮在 macOS 上验证了真实 PTY、Terminal.app、真实 Provider 与真实工具执行；Windows Terminal/ConHost、Linux 桌面终端与非 macOS 输入法不可用，标记为 **NOT_VERIFIED**。CI 在 macOS（Apple Silicon、Intel）、64 位 Linux 与 64 位 Windows 上构建并对发布包做冒烟测试。Windows 上受限 Shell 仍可创建原本缺失的 `AGENTS.md`，该文件随后会作为项目上下文被读取，但仍不携带任何授权；既有受保护对象继续受 OS 栅栏保护。以该方式创建的 `.leveler` 定义未经批准绝不会被采纳。FullAccess 仍是明确的用户权限边界，而不是 OS 保证。安装包未经过 Apple 公证或 Microsoft 签名。

本版命令行安装包支持 macOS（Apple Silicon、Intel）、Linux x86_64 和 Windows x86_64。没有 Linux ARM 包。桌面客户端需从源码构建，不包含在发布包中。安装和更新见[首页](../README.zh-CN.md)，完整版本历史见[更新日志](../CHANGELOG.zh-CN.md)。
