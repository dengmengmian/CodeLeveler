# CodeLeveler Mobile freeze

**Status:** FROZEN  
**Tag:** `mobile-beta-mvp`  
**Chinese:** [`MOBILE_FREEZE.zh-CN.md`](MOBILE_FREEZE.zh-CN.md)

Feature work on `apps/leveler-mobile` stops at this tag. Further Mobile investment waits on real Beta users.

Allowed until then: fixes that restore the already-shipped loop (pairing, signed frames, approvals, steer, `fetch_attachment` safety). Not allowed: Push, fleet UI, voice, a phone IDE, or a client rewrite.

`leveler remote` remains **Unstable** in [`STABILITY.md`](STABILITY.md). This freeze is product investment, not a protocol 1.0 promise.
